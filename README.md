# Karakol Travel Guide (React)

Туристический веб-гид по Караколу для дипломного проекта.

## Возможности

- **Главная** — обзор региона и популярные маршруты
- **Маршруты** — каталог туров с фильтрами и карточками
- **Маршрутизатор** — планирование поездки по дням (интересы, точки, время)
- **Достопримечательности** и **Где поесть**
- **Туристам** — практическая информация
- **Контакты** — форма обратной связи
- **Админ-панель** — вход, управление маршрутами, просмотр сообщений

## Запуск

```bash
cd karakol-landing
npm install
npm run dev
```

Сайт: http://localhost:5173

## Админ

- URL: http://localhost:5173/admin/login

- Пароль: `admin123`

```bash
npm run build
```
